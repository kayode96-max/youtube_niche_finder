Where do I get an API key?
It's free from Google, takes about two minutes, and this app talks to it directly — your key never leaves your browser except to call Google's API.
  1. Go to the Google Cloud Console credentials page and create a project (or pick an existing one).
  2. Open APIs & Services → Library, search for "YouTube Data API v3", and click Enable.
  3. Back on the Credentials page, click Create Credentials → API key, then copy it into the field above.
The free tier gives you 10,000 quota units a day — each search here costs about 100 units, so roughly 90–100 searches per day at no cost.
